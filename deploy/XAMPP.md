# XAMPP

1. Extract DogoFlow to `C:\xampp\htdocs\DogoFlow`.
2. Start Apache and MySQL.
3. Import `database/schema.sql` into MySQL.
4. Leave the project structure unchanged.
5. Open `http://localhost/DogoFlow/public/`.
6. Admin: `http://localhost/DogoFlow/public/admin/dashboard` (or `.php`).

The URL helper detects `/DogoFlow/public` automatically, so CSS, images, links and redirects work from the subdirectory.
